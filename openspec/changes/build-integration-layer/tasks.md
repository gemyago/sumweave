The numbered groups are the ordered implementation phases and the recommended
sequential chunks. Keep each group together unless the implementer proves it
cannot fit one session. After every group, use `openspec apply`, run its focused
checks plus the repository completion command, obtain the required shallow
review, and commit before starting the next group. The design's manual smoke E2E,
deep final review, user approval, archive, and submission remain completion gates
rather than separate final-verification checkbox tasks.
